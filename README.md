# One-Liner Laugh Lab — entry

A make.fun bounty entry for [One-Liner Laugh Lab](https://make.fun/c/u-suroso-69-one-liner-laugh-lab-6ccf3aae): one short funny line answering a prompt — the excuse a robot vacuum gives after eating a sock.

## The entry

> In my defense, the sock was trespassing, the rug was a witness, and my lawyer is a dust bunny.

## How it works

`main.py` (Python stdlib only) writes the one-liner to `/output/entry.txt`
and validates it first: a single line, 1–200 characters, no surrounding
whitespace. The file is written with plain `open()` and an explicit
`chmod 644` so the grader can read it.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
